# 🚀 Proyecto de Pruebas de Desarrollo - Laravel

Entorno de pruebas y desarrollo backend/frontend desarrollado con **Laravel**. Este repositorio sirve como base para prácticas, pruebas de modelos, migraciones, seeders y consumo de APIs.

---

## ⚙️ Requisitos Previos

Asegúrate de tener instalado en tu computadora lo siguiente antes de clonar el proyecto:
* **PHP** (versión recomendada por Laravel)
* **Composer**
* **Git**
* **MySQL / MariaDB** (puedes usar XAMPP)

---
